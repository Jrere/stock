使用说明

快速开始

  1. 在侧边栏填入 DeepSeek API Key 并保存
  2. 输入股票代码（如 AAPL、600519）
  3. 选择分析维度（可多选）
  4. 点击「开始分析」，等待报告生成

支持市场

  • 美股 — AAPL、TSLA、NVDA 等
  • A股 — 6 位代码如 600519、000858
  • 港股 — 5 位代码如 09988、00700

安全

API Key 仅存浏览器本地，请求通过后端代理转发，不暴露给前端。
